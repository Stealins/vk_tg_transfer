# vk_tg_bridge

Бот пересылает сообщения из ВКонтакте в Telegram. Каждому VK-чату (личной переписке, беседе, сообществу)
соответствует отдельный топик в вашей Telegram-супергруппе с темами.

```
VK: переписка с Иваном  ──►  TG-супергруппа / топик «Иван»
VK: беседа «Работа»     ──►  TG-супергруппа / топик «Работа»
```

В Telegram сообщение приходит в виде:

> **Иван Петров** · 09.10.2026 14:05
> Привет!

Пересылка односторонняя: VK → Telegram. Пересылается только текст, вложения пока пропускаются.

## Что понадобится

- **Windows** (команды ниже написаны для неё) и **Python 3.14** (на нём проверялось).
- **Microsoft Edge**: через него бот входит в ваш аккаунт VK (отдельный браузер скачивать не нужно).
- **Свой Telegram-бот** и **своя супергруппа**. В репозитории их нет, их создаёт каждый для себя (см. ниже).
- Если Telegram у вас доступен только через VPN, понадобится SOCKS5-прокси (см. «Прокси»).

## Установка

```
git clone https://github.com/Stealins/vk_tg_bot.git
cd vk_tg_bot
python -m venv myvenv
myvenv\Scripts\python -m pip install -r requirements.txt
```

Папки `myvenv/` в репозитории нет: виртуальное окружение создаётся у каждого своё, а нужные библиотеки
перечислены в `requirements.txt`.

## Настройка

Все личные данные хранятся в папке `personal_data/` в корне проекта. Её нет в репозитории (она в `.gitignore`),
поэтому создайте её сами:

```
mkdir personal_data
```

### 1. Создайте Telegram-бота → `personal_data/token_tg.txt`

1. Напишите [@BotFather](https://t.me/BotFather) команду `/newbot` и следуйте подсказкам.
2. Он пришлёт токен вида `1234567890:AAH...`. Сохраните его в `personal_data/token_tg.txt` (одной строкой, больше ничего).

Токен даёт полный доступ к боту, поэтому никому его не показывайте и не коммитьте.

### 2. Создайте супергруппу с темами → `personal_data/group_id.txt`

1. Создайте в Telegram новую группу.
2. В настройках группы включите **Темы** (Topics). Группа автоматически станет супергруппой.
3. Добавьте в неё своего бота и сделайте его **администратором** с правом **управлять темами**.
4. Узнайте id группы, это отрицательное число вида `-100xxxxxxxxxx`. Проще всего так:
   - напишите в группе любое сообщение;
   - откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, подставив свой токен;
   - найдите в ответе `"chat":{"id":-100...` — это и есть id.

   Также id видно в адресной строке [Telegram Web](https://web.telegram.org/a/), если открыть группу.
5. Сохраните id в `personal_data/group_id.txt`.

### 3. Прокси

По умолчанию бот ходит в Telegram через SOCKS5-прокси `127.0.0.1:10808` (так работает VPN автора).
Если у вас другой адрес прокси, поменяйте `TG_PROXY` в `vk_tg_bridge/config.py`. Если прокси не нужен,
замените там строку `TG_PROXIES = ...` на `TG_PROXIES = {}`.

### 4. Войдите в VK

```
myvenv\Scripts\python -m vk_tg_bridge.vk_auth
```

Откроется окно Edge со страницей VK. Войдите в свой аккаунт, бот сам заберёт токен. Сессия сохраняется
в `personal_data/browser_profile/`, дальше бот обновляет токен сам. Если вход не выполнен,
бот при запуске сам откроет это окно.

В `personal_data/browser_profile/` лежит доступ к вашему аккаунту VK, поэтому никому не передавайте эту папку.

В итоге должно получиться:

```
personal_data/
  token_tg.txt       ← вы
  group_id.txt       ← вы
  token.txt          ← создаст бот (VK-токен)
  token_meta.json    ← создаст бот
  browser_profile/   ← создаст бот
  state.json         ← создаст бот (привязки чатов и очередь сообщений)
```

## Запуск

Из корня проекта:

```
myvenv\Scripts\python -m vk_tg_bridge
```

Останавливать бота нужно через **Ctrl+C**: тогда он сохранит состояние. Если убить процесс жёстко
(например, кнопкой Stop в VS Code), могут пропасть изменения за последние секунды.

Лог пишется в консоль и в `bot.log`.

В VS Code готовые конфигурации запуска лежат в `.vscode/launch.json` («Бот», «Вход в VK», «Тесты»).
Перед этим выберите интерпретатор `myvenv\Scripts\python.exe` (`Ctrl+Shift+P` → *Python: Select Interpreter*).

## Как добавить VK-чат

Всё общение с ботом идёт в ветке **General** вашей супергруппы.

1. Отправьте `/start` и нажмите **«➕ Добавить VK-чат»**.
2. Введите название топика.
3. Введите `peer_id` VK-чата:
   - личная переписка — id пользователя (положительное число);
   - беседа — `2000000000 + id беседы` (беседа 5 → `2000000005`);
   - сообщество — минус id сообщества.

   Номер чата обычно видно в адресной строке, если открыть переписку в веб-версии VK.

Бот создаст топик, и новые сообщения из этого чата будут приходить туда. `/cancel` прерывает добавление.

Если удалить топик вручную, при следующем запуске бот снимет привязку и напишет об этом в General.

## Тесты

```
myvenv\Scripts\python -m unittest
```

Тесты не ходят в сеть и не трогают `personal_data/`.

## Структура

```
vk_tg_bridge/
  __main__.py        точка входа: главный цикл бота
  config.py          пути к файлам и настройки прокси
  dialog.py          диалог с ботом в General, создание топиков
  relay.py           очередь VK → Telegram и формат сообщений
  storage.py         сохранение состояния (state.json)
  tg_client.py       запросы к Telegram Bot API
  vk_client.py       запросы к VK API
  vk_longpoll.py     получение новых сообщений из VK (long poll)
  vk_auth.py         получение VK-токена через браузер
  logging_config.py  логирование (токены в логе маскируются)
tests/               тесты (unittest)
```
